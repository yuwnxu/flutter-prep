## Правило «четырёх вопросов» перед каждой задачей

1. Сколько она стоит? (смотрите таблицу спринта)
2. Сколько минут займёт?
3. Нужна ли она для других задач (например, сетевой слой нужен всем экранам)?
4. Что снимут, если не сделаю?

## Универсальный порядок внутри спринта

1. Ветка и перенос не более двух карточек в «В работе».
2. Каркас: папки, DI, пакеты.
3. Самые дорогие по баллам задачи.
4. Логирование и комментарии — **сразу при написании**, не в конце.
5. Проверка на втором размере экрана.
6. Коммит на каждую карточку, перенос в «Готово к тестированию» с хэшем.
7. Pull request и merge за 5 минут до конца.

## Что даёт половину баллов или ноль

| Ситуация | Последствие |
|---|---|
| Нет комментариев и логов | **×0,5** почти в каждом критерии |
| Нет библиотеки UIKit | Верстка компонентов не проверяется |
| Нет компонента в StoryBook | Половина баллов компонента |
| Архитектура не по заданию | 0 за слои |
| Файл лежит вне своей папки | −0,1 за файл |
| Приложение не собирается из репозитория | Ничего не оценивается |
| Карточка не в «Готово к тестированию» | Задача не проверяется |
| Больше двух задач «В работе» | Ограничение баллов |
| Нет мёржа в main | Потеря баллов модуля Г |

## Подготовка к чемпионату: что тренировать

| Навык | Как тренировать | Критерий готовности |
|---|---|---|
| UIKit за 90 минут | Секундомер, макет из симуляции + недостающие компоненты | Все 10 компонентов, StoryBook, PR |
| Сетевой слой за 70 минут | Любой публичный API (например, jsonplaceholder) | 11 методов, тесты проходят |
| Экран по макету за 10 минут | Открыть Figma, собрать экран | Разница с макетом не заметна |
| Три слоя без подсказок | Экран логина «с нуля» | Domain без импортов Flutter |
| Игра-пазл за 30 минут | Шаблон с общим контроллером | Победа, время, отправка |
| Git за 3 минуты | Ветка, коммит, push, PR, merge | Без ошибок и без документации |
| Комментарии и логи | Писать при каждом классе | Шапка + 4 точки логов |

## Свой комплект шпаргалок

Перед чемпионатом подготовьте (то, что можно использовать по правилам, уточните у главного эксперта):

- Список пакетов и версий.
- Сниппеты: шапка класса, `AppLog`, `HttpApiClient`, шаблон экрана с `ScreenState`.
- Команды Git.
- Таблицу 11 запросов.

## День перед стартом

- Проверьте `flutter doctor` и эмуляторы разных размеров.
- Обновите Flutter до версии стенда, которую сообщат организаторы.
- Выспитесь. Усталость стоит дороже одной непрочитанной главы.
