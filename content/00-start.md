## Что такое это задание

Региональный этап «Профессионалов» по компетенции **«Разработка мобильных приложений»**. Вы за три дня (18 часов) делаете мобильное приложение для игры двух соперников: расписание боёв, поиск соперника, две игры-пазла (**Image** и **Circle**), статистика. Дизайн дан в Figma, бэкенд — готовый SaaS по REST API.

| Параметр | Значение |
|---|---|
| Длительность | 18 часов, 3 конкурсных дня |
| Модулей | 7 (5 обязательных + 2 вариативных) |
| Сумма баллов | 100 |
| Минимальные ОС | Android 14, iOS 18 |
| Работа сдаётся | через Git (удалённый репозиторий организаторов) |
| Задачи выдаются | в таск-трекере, помечены спринтом |

:::

## Правила, за которые снимают баллы

1. **Канбан-доска.** Колонки: «Готово к разработке» → «В работе» (не более 2 задач одновременно) → «Готово к тестированию» (вы сами переносите карточку и указываете **коммит**) → «Завершена» (переносят эксперты). Карточка не в «Готово к тестированию» — задача не проверяется.
2. **Git.** Ветка на каждый спринт, проект сохранён в ветку, pull request / merge в `main`. Если приложение не собирается из репозитория, работа **не оценивается**.
3. **Дизайн строго по Figma.** Шрифты, отступы, пропорции, цвета.
4. **Адаптивность.** Без больших пустот, без искажений, без горизонтального скролла, шрифты не заменяются системными.
5. **Интернет почти недоступен.** Один выделенный компьютер, **10 минут на спринт**, очередь не чаще раза в 10 минут. Пакеты нужно заранее согласовать с главным экспертом в день ознакомления.
6. **Документирование и логи** во всех спринтах (раздел «Комментарии и логи»).

::: warn
Из пункта 5 следует важное: **заранее выучите, какие пакеты вам нужны и как их подключать**, и держите под рукой шпаргалку. На площадке нельзя долго искать документацию.
:::

## Пакеты, которые стоит согласовать заранее

| Задача | Пакет |
|---|---|
| Сеть | `http` (или `dio`) |
| Логи | `logger` |
| Хранение настроек и сессии | `shared_preferences`, `flutter_secure_storage` |
| Кэш картинок | `cached_network_image` |
| Фото | `image_picker` |
| Уведомления | `flutter_local_notifications`, `timezone`, `permission_handler` |
| PDF | `pdfx` или `flutter_pdfview` |
| Графики | `fl_chart` (или рисовать самим через `CustomPainter`) |
| Тесты | `flutter_test`, `mocktail`, `http/testing.dart` (идёт вместе с `http`) |
| Метрика | `appmetrica_plugin` |
| Адаптив | `vize` (вы уже используете) |
| Состояние | `get` (GetX) или `provider` / `flutter_bloc` |

## Как пользоваться сайтом

- Идите по этапам слева направо: от «что такое программирование» до разборов спринтов.
- Отмечайте темы как **изученные** (прогресс хранится в вашем браузере).
- После каждого этапа решайте **тренажёр** с вопросами.
- Перед каждой репетицией спринта откройте раздел «Чек-лист баллов».
