# Flutter к Профессионалам

Учебный сайт для подготовки к региональному чемпионату «Профессионалы» по компетенции «Разработка мобильных приложений».

- `content/*.md` — темы
- `src/` — стили, скрипт, шаблон, вопросы тренажёра
- `build.py` — сборка в `dist/index.html` (нужны Python 3 и pandoc)
- `.github/workflows/pages.yml` — автодеплой `dist` на GitHub Pages

Сборка: `python3 build.py`
